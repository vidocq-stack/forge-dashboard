# Interface multilingue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Le dashboard s'affiche en français, anglais, allemand ou néerlandais : la langue du navigateur par défaut,
ou celle choisie dans le menu de l'avatar et mémorisée.

**Architecture:** Un package `i18n` sans Vaadin (`Messages`, quatre fichiers `.properties`) sert à la fois l'UI et
les pages servlet. Vaadin reçoit un `I18NProvider` (pour choisir la langue de l'UI d'après le navigateur) ; les vues
prennent un `Messages` de la langue de l'UI par `ui/Texts.current()`. Les modèles purs reçoivent leur `Messages` en
paramètre. Les résultats métier qui portaient une phrase française (`OrgAdminResult.Rejected`,
`CallbackResult.Denied`) portent une clé et ses arguments.

**Tech Stack:** Java 25 JPMS, Vaadin Flow 25.3, Vidocq 0.4.0-SNAPSHOT (Vauban, Mansart, Flyway), JUnit 5.

**Spec:** `docs/superpowers/specs/2026-11-15-i18n-design.md`

## Global Constraints

- Langues : `fr`, `en`, `de`, `nl` ; l'anglais est le repli de toute autre langue.
- Noms affichés dans le menu, chacun dans sa langue : « Français », « English », « Deutsch », « Nederlands » ;
  l'entrée « Navigateur » (traduite) efface le choix.
- Fichiers : `forge-dashboard-app/src/main/resources/i18n/messages.properties` (anglais) et `messages_fr`,
  `messages_de`, `messages_nl`, UTF-8, format `MessageFormat` ; les apostrophes s'écrivent telles quelles.
- Non traduit : noms d'org/repo/runner/job, titres de PR, auteurs, familles d'agents, journaux, exceptions.
- Pas de nouvelle dépendance ; pas de `ResourceBundle.getBundle` ; panneaux et modèles testables sans session.
- Préférence : colonne `language TEXT NULL` de `user_pref` (Flyway `V2`), `null` = navigateur.
- Une traduction manquante casse un test, jamais l'écran : chaque tâche qui ajoute une clé l'ajoute aux quatre
  fichiers, et le test de complétude tourne dans chaque `task-done`.
- Build : `./mvnw -ntp -o clean verify` (toujours `clean`).

## Review Focus

- Un navigateur en variante régionale (`de-CH`, `nl-BE`, `fr-CA`) doit obtenir sa langue, pas l'anglais.
- Un en-tête `Accept-Language` absent ou malformé sur les pages servlet donne l'anglais, sans erreur 500.
- Une préférence en base qui n'est plus une langue prise en charge (`xx`) retombe sur le navigateur.
- Les libellés allemands, plus longs, ne doivent pas casser l'en-tête ni les tableaux à 390 px (vue téléphone).
- Une apostrophe ou un `{0}` dans une traduction s'affiche correctement dans les quatre langues.
